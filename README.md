# Nova Style

Nova Style is a Django-based e-commerce website with product management,
category management, coupons, offers, orders, payments, and an admin/staff dashboard.

## Features

- User registration and login
- Product browsing
- Product categories
- Product offers
- Category offers with start and end dates
- Shopping cart
- Wishlist
- Coupon management
- User-side coupon display
- Order management
- Order returns
- Razorpay payment integration
- Payment failure handling
- Payment retry
- Staff/admin dashboard
- Sales reports
- Top-selling products
- Top-selling categories

## Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- PostgreSQL 
- Razorpay
